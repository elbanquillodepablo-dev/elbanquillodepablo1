# El Banquillo de Pablo 🏟️

Tienda online de camisetas de fútbol con panel de administración. React + TypeScript + Vite + Tailwind v4 + Supabase.

## Inicio rápido

Requiere Node.js 22.x y un proyecto de Supabase.

```bash
npm install
```

Crea `.env.local` a partir de `.env.example` y configura la URL y la publishable key de Supabase (`VITE_SITE_URL` es opcional en local). Luego ejecuta:

```bash
npm run dev
```

La guía completa para configurar Supabase y desplegar en Vercel está en [CONTEXT.md](CONTEXT.md).
