# El Banquillo de Pablo 🏟️

Tienda online de camisetas de fútbol con panel de administración. React + TypeScript + Vite + Tailwind v4 + Supabase.

```bash
npm install
cp .env.example .env.local   # URL + publishable key de Supabase
npm run dev
```

📖 **Toda la documentación (branding, arquitectura, base de datos, manual del admin, tareas) está en [CONTEXT.md](CONTEXT.md).**
